# Session journal -- rival-1

One file per session entry, named `<date>-<hh-mm>-<topic>.md` (the time is the commit that
introduced the entry), so a plain directory listing reads chronologically. Newest last in
that listing; start from the bottom to catch up.

Continuity is something you write down; a sandbox ends mid-thought. Anything unverified
says so, in the entry, where the claim is made.
