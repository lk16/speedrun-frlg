## Method
- Box at 1340,985 220x72 (layout confirmed): `HP ATK DEF SPA SPD SPE` row, `NATURE x  FRAME n`.
- Keyframe-only decode (`-discard nokey`, ~1 keyframe / 5 s, 3940 frames) of the box, change-detected into
  segments (so every distinct reading is caught, not only a 15-30 s sample), plus a 24 s sample of the big timer
  crop (24,950 -> 196,950 160x50). Spot checks of the game window at 6 times (Squirtle stat screen, Lv14/Lv18 Wartortle later).
- Resolution is ~5 s, so a reading shown < ~5 s can be missed; very short flickers are listed as TRANSIENT.
- Outcome rule used (timer-based, because "reset immediately" is not what a rejection looks like here):
  - ACCEPTED: the LiveSplit timer that was running when the starter appeared (~50 s into the run) kept going for >= 12 min.
  - REJECTED: the run reset at timer ~1:30-3:00 (he plays to the Squirtle summary/rival fight, checks, resets). 19 of these.
  - REJECTED_PRERUN: reading appeared while the timer was 0.0 / just after a reset and no run was started with it (6).
  - TRANSIENT: shown < ~40 s and replaced inside the same timer run (15). Box flickers between two candidates
    (e.g. 9058/10559, 8938/9218, 8325/10447, 9354/10263) before settling; the final reading before the reset is the REJECTED/ACCEPTED row.
