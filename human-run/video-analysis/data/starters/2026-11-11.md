  blank nature/frame). The first new reading appears at run timer ~0:46-0:55.
- Often a "preliminary" reading shows 6-12 s, then is replaced within the same run (8 of 19 runs).
- A red `OFF SCREEN n / ANCHORS a . b . c` panel replaces the IV box for 6-12 s at run timer
  ~1:40-2:05 in every run (n = 0..4; anchors ~1660-2230 / 2490-3065 / 3790-4385, climb with
  the run). Not a starter; ignored.
- Some runs update the box again ~3:05-3:10 (A4 Mild->Rash 10529->10527, A13 Mild 9969 ->
  Serious 9965) or ~10:30 (A18). In A13 the in-game Lv6 stat screen (HP23 A12 D13 SpA11 SpD14
  Spe11) matches the LATER reading 30/21/11/7/27/18 Serious, not the earlier 9969 reading, so
  the last reading in a run is the real Squirtle; earlier ones are predictions. (Level-6 stat
  arithmetic was done by hand, no decompiled/ citation: treat as a guess about the mechanism.)
- The IV box lags: after a reset the old starter stays up ~45 s into the next run.
- Overlay text over the game window: "Runs past Brock: 3/15" (seen at t=8120).
