## What the box actually is (important)
It is a **prediction overlay**, not a post-pick readout:
- Zeros + empty NATURE/FRAME right after a reset; "OFF SCREEN n / ANCHORS a b c" frames mid-attempt.
- During the walk to the lab it **flickers between candidate starters** (e.g. 35:46 Rash 8273, 35:58 Mild 8344,
  36:18 Rash 8273, 36:34 Mild 8344), the seed FRAME changing with them. Values are stable only in the last ~minute.
- It keeps showing the last reading through the next boot until zeros appear (or not at all), so a long
  segment does not mean a long run.
- **It does not always match the game.** Att5 (box Rash 9937) -> in-game summary says SERIOUS nature (= the
  Serious 10448 shown at the end of att4). Att1 (box Mild 10697): in-game Lv5 stats HP19 A10 D9 SA11 SD11 Sp10
  cannot come from it (Def 9 needs a -Def nature). Att6 (box Mild 10748): partial mismatch. Att9 (box Careful 11353):
  exact match (HP20 A9 D12 SA9 SD12 Sp9). So per-starter ACCEPTED/REJECTED below is "attempt outcome while this
  was the last box value", not proof the box value was the Squirtle he got.

## Outcome definition used
Attempts are ~8-25 min for accepted ones, so: ACCEPTED = run continues past the rival fight / stats check
(end timer >= ~4:50, usually 8-14 min, last one 2:45 h). REJECTED, three shapes:
1. lab, before the fight (reset at total timer 1:37-2:15): attempts 2,3,7,8,14, 24
2. rival fight start (2:17-2:23 timer): 18, 19, 21
3. after the rival fight, at the Lv5/Lv6 summary/stats page (2:20-3:16 timer): 1,4,5,6,9
Rejected attempts last 108-200 s (median ~148 s).
