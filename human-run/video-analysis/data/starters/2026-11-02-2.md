## What the box does
- Shows HP/ATK/DEF/SPA/SPD/SPE IVs, NATURE, FRAME (seed frame). It alternates
  with an `OFF SCREEN n  ANCHORS a . b . c` panel around run timer 1:40-2:00
  (looks like an RNG-tracking tool; the IVs are predictions that refine during an attempt).
- Within one attempt the box usually shows two values: an early one (~timer 0:50)
  that is replaced ~10-30 s later (no reset), and the final one that matches the pick
  (Squirtle received at ~timer 1:40). The first one is labelled SUPERSEDED.
- After a reset the box keeps showing the last (or a new) value ("IDLE", 5 of them),
  or all zeros with blank nature/frame (between attempts, e.g. 0:49:40-0:54:10).
- The same FRAME can show different IVs (8328 Mild vs 8328 Calm): FRAME is the seed
  frame, the IVs depend on the rest of the RNG path.
- Main97Bot chat in a probe frame: only squirtles with 26+ Speed and perfect Torrent
  (SpA 31) are run for Brock; consistent with data below.
