## Clemi's Skip (iamClemi)
- [snippet] Found by iamClemi soft-resetting for a Charmander on the Switch port; pressing L opens the Help menu, which skips the capture fanfare. Saves 2.68 s per catch; main impact is Round 2 (60 species). Sources: TheGamer, GamesRadar, Kotaku above.
- [snippet] Platform: Switch-specific (Help menu does not exist on GBA). Source: games.gg above. Implication (my inference, not sourced): it is not usable on GBA/GBI console boards.
